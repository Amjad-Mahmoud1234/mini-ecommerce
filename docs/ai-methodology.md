# AI Methodology

## AI Tools

During this project, I used ChatGPT and Cursor to help me during the development process.

## ChatGPT

I used ChatGPT mainly to discuss and review technical decisions during the project.

Some examples of how I used ChatGPT:

- Discuss the technology choices before starting the implementation.
- Discuss database decisions like storing stock at the ProductVariant level and price at the Product level.
- Review backend code and find possible problems.
- Discuss how to organize frontend pages, components, and services.
- Help with debugging problems during development and deployment.
- Explain the steps for deploying the frontend and backend on Render and connecting backend to Neon.
- Discuss if adding some technologies or extra layers is needed for this project.

I used these discussions to understand the decisions before applying changes to the project.

## Cursor

I used Cursor for specific implementation tasks to save development time.

Some examples of how I used Cursor:

- Generate the `products.json` file with 15 products and their variants.
- Help create and update database seed for products and test user.
- Help create the frontend design and UI based on the requirements and instructions that I provided.
- Create Zod validation schemas after I defined what should validated for each route.
- Make small refactoring changes and reduce repeated code.
- Make CSS and responsive design changes.
- Help with small changes related to API integration between the frontend and backend.

I gave Cursor specific tasks and explained what I wanted before using it.

I reviewed changes and tested the application after applying them.
